# واجهة نقطة البيع للصيدلية

## التشغيل
افتح `index.html` في أي متصفح (Chrome أو Edge). لا يحتاج خادماً أو تثبيتاً.
الخط يُحمّل من Google Fonts عند توفر الإنترنت، وبدونه يستخدم خط النظام.

## الملفات
- `index.html` — هيكل الواجهة
- `css/style.css` — التصميم والألوان (غيّر `--accent` لتغيير اللون الرئيسي)
- `js/data.js` — الأدوية والتصنيفات (بيانات تجريبية: استبدلها ببياناتك)
- `js/app.js` — منطق الفاتورة والبحث والأزرار

## اختصارات لوحة المفاتيح
- `F2` البحث / مسح الباركود (Enter يضيف أول نتيجة)
- `F9` إتمام البيع وطباعة الفاتورة

## ملاحظات
- البيانات تُحفظ في الذاكرة فقط وتعود عند تحديث الصفحة. للربط الحقيقي
  أرسل الفاتورة إلى الخادم داخل الدالة `checkout()` في `js/app.js`.
- حقل `barcode` في `data.js` يُطابَق تماماً عند البحث.
